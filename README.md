## Sweet Whisper для Android

Это голосовая клавиатура: вы диктуете там же, где обычно пишете. Открыли чат, нажали на клавиатуре микрофон, сказали — слова падают прямо в сообщение. Ничего копировать и никуда переключаться не нужно.

- Диктовка в любом приложении — прямо с клавиатуры
- Всё считается на телефоне, записи не покидают устройство
- Русский слышит GigaAM — с запятыми и заглавными буквами
- Модель подбирается под ваш телефон на первом запуске
- История с поиском, свой словарь терминов, произносимая пунктуация
- Плитка в шторке, виджет и системный голосовой ввод
- Бесплатно, без рекламы и без аккаунта

[Как установить APK и включить клавиатуру →](https://sweetwhisper.app/android/)

## Требования

**Windows**

- Windows 10/11 x64
- Для GPU-ускорения: любая видеокарта с Vulkan (NVIDIA / AMD / Intel); без GPU работает на CPU с лёгкими моделями
- ~2–4 ГБ на диске под модели (загружаются при первом запуске по вашему выбору)

**Android**

- Android 9 и новее
- 0,2–1 ГБ под модель — размер зависит от того, какую выберете

## Нашли баг? Есть идея?

Откройте [Issue](../../issues/new/choose) — шаблоны подскажут, что приложить. В приложении есть кнопка «Скопировать диагностику» (Настройки → Помощь) — вставьте её вывод в репорт, это сильно ускоряет починку. Отвечаем быстро: продукт активно развивается, ранние пользователи получают фиксы в течение дней, а не месяцев.

Вопросы, впечатления и пожелания — в [Обсуждения](../../discussions).

## Приватность

Аудио и распознанный текст **никогда не покидают ваше устройство**. Сеть используется только для: загрузки моделей по вашему запросу, проверки обновлений и отчёта об ошибке — только когда вы сами нажимаете кнопку отправки. Подробнее — [политика приватности](https://sweetwhisper.app/privacy/).
