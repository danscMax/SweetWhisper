Зажмите горячую клавишу — говорите — отпустите. Текст появляется в том приложении, где стоит курсор: мессенджер, почта, IDE, браузер. Без интернета, без подписок, без отправки голоса в облако.

## Возможности

|  |  |
|---|---|
| 🎙️ **Диктовка в любое окно** | Push-to-talk или переключатель; текст вставляется прямо в активное приложение |
| 🇷🇺 **Русский — первоклассный** | GigaAM — модель, обученная на русском; плюс Whisper и Parakeet для английского и 90+ языков |
| 🔒 **100% оффлайн** | Распознавание целиком на вашем GPU/CPU (Vulkan, DirectML). Сеть — только для загрузки моделей и проверки обновлений |
| ⚡ **Живой предпросмотр** | Текст появляется на экране прямо во время речи |
| 🗣️ **Голосовые команды** | «Котик, отмена», «Котик, открой блокнот» — управление голосом без рук |
| 🤖 **LLM-очистка текста** | Локальная языковая модель убирает слова-паразиты, расставляет пунктуацию, переводит — тоже оффлайн |
| 👤 **Профили под приложения** | Разные настройки для IDE, мессенджера и документов — переключаются сами |
| 📜 **История диктовок** | Полнотекстовый поиск по всему, что вы надиктовали |

## Скачать

Загрузки — на [sweetwhisper.app](https://sweetwhisper.app/#download) (установщик и portable). Релизы будут дублироваться и здесь, во вкладке [Releases](../../releases).

**Бесплатная версия** включает весь локальный стек распознавания без ограничений — все движки, все модели, диктовка, история. **Pro** (разовая покупка, не подписка) добавляет живой предпросмотр, LLM-очистку, профили и другие суперспособности — подробности [на сайте](https://sweetwhisper.app/#pricing).

## Требования

- Windows 10/11 x64
- Для GPU-ускорения: любая видеокарта с Vulkan (NVIDIA / AMD / Intel); без GPU работает на CPU с лёгкими моделями
- ~2–4 ГБ на диске под модели (загружаются при первом запуске по вашему выбору)

## Нашли баг? Есть идея?

Откройте [Issue](../../issues/new/choose) — шаблоны подскажут, что приложить. В приложении есть кнопка «Скопировать диагностику» (Настройки → Помощь) — вставьте её вывод в репорт, это сильно ускоряет починку. Отвечаем быстро: продукт активно развивается, ранние пользователи получают фиксы в течение дней, а не месяцев.

## Приватность

Аудио и распознанный текст **никогда не покидают ваш компьютер**. Сеть используется только для: загрузки моделей по вашему запросу, проверки обновлений и отчёта об ошибке — только когда вы сами нажимаете кнопку отправки. Подробнее — [политика приватности](https://sweetwhisper.app/privacy).
