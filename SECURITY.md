# Security Policy / Политика безопасности

**RU:** Нашли уязвимость — пожалуйста, НЕ публикуйте её в открытых Issues. Напишите на **security@sweetwhisper.app** с описанием и шагами воспроизведения. Ответим в течение 72 часов; исправления уязвимостей выходят вне очереди. После фикса с удовольствием укажем вас в благодарностях (если хотите).

**EN:** If you found a vulnerability, please do NOT open a public issue. Email **security@sweetwhisper.app** with a description and reproduction steps. We reply within 72 hours; security fixes ship out of band. Credit given after the fix if you wish.

## Scope

- SweetWhisper desktop app (Windows)
- sweetwhisper.app website and relay service

## Out of scope

- Vulnerabilities in upstream engines/models (whisper.cpp, ONNX Runtime, etc.) — report to their maintainers (we will still appreciate a heads-up)
